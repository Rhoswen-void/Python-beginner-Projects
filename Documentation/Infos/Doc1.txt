1.List Comprehension: A concise way to create lists in Python.
                      Compact and Easier to read than traditional loops
                      [expression for value in iterable if condition]

2.Match Case statement: An alternative to using elif statements, Executes some code if a value matches
                        a case. Better and Cleaner syntax.

3.Modules: A file containing code you want to include in your program, use 'import' to use these Modules
           useful to break up large program reusable seperate files. Also when a python file is imported
           as a module, python creates a __pycache__ folder that contains the byte code for the module
           so the next time we import the program file in another program it's executed faster.

4.Variable scope: where a variable is visible and accessible
  Scope resolution: (LEGB) Local -> Enclosed -> Global -> Built-in

5.if __name__ == '__main__': (This script can be imported  OR run standalone)
                             Functions and classes in this module can be reused
