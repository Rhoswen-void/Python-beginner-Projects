Object = A "bundle" of related attributes (variables) and methods (functions)
         Ex. phone, cup, book
         You need a "class" to create many objects

Class = A blueprint for an object.
        To create an object in a class we use a special kind of method called a constructor.
        We use function "def __init__(self,parameter1,parameter2...):"

        Eg: To access some the characteristic of we <object_name>.attribute to access that attribute
            for the given object.

Methods: Methods are actions that our object can perform.

Class varaibles: Shared among all instances of a class.
                 Defined outside the constructor
                 Allows you to share data among all objects created from that class
                 Instance variables are defined in the constructor.

Inheritance: Allows a class to inherit attributes and methods from another class.
             Helps with code reusability and extensibility
             class Child(Parent)

Multiple Inheritance: Inheriting from more than parent C(A,B)

Multilevel Inheritance: inherit from a parent that inherits from another 
                        C(B) <- B(A) <- A
